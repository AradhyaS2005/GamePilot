
# GamePilot 🎮

GamePilot is a Windows desktop application that transforms a game controller into a customizable mouse and keyboard controller.

## Features

- Controller detection
- Real-time joystick monitoring
- Button input detection
- Mouse and keyboard mapping
- Customizable controller profiles

## Tech Stack

- Python
- PyGame
- PySide6
- Windows SendInput API

## Development Status

Currently in Phase 1: Controller Detection.

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd GamePilot

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt
python main.py
```
